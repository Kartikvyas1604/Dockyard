# Dockyard Mobile (placeholder)

Expo Router shell for the maker desk on mobile. The desk is a keyboard-heavy
trading surface — mobile is scoped for monitoring (positions, intel status),
not for shipping strategies. Shared logic comes from `@dockyard/*` packages;
`.native.tsx` overrides resolve automatically via Metro.

Install deps and run with `pnpm --filter @dockyard/mobile start` once the
Expo SDK is pinned for the target release.
